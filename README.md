# Análise Exploratória dos Microdados do ENEM 2023

Análise exploratória dos microdados do ENEM 2023 investigando 
fatores socioeconômicos e sua relação com o desempenho dos participantes.

## Sobre o projeto
Análise exploratória investigando como fatores como renda familiar, 
escolaridade dos pais, tipo de escola e localização influenciam 
o desempenho dos estudantes concluintes do ensino médio em 2023.

## Como reproduzir
1. Baixe os microdados do ENEM 2023 no site do INEP: (https://www.gov.br/inep/pt-br/acesso-a-informacao/dados-abertos/microdados/enem)
2. Faça upload do arquivo para o Google Drive
3. Ajuste o caminho do arquivo no notebook para o seu Drive
4. Abra o notebook no Google Colab pelo link disponível no repositório

## Tecnologias utilizadas
- Python
- Pandas
- Matplotlib
- Google Colab
